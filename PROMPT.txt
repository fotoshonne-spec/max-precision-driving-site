CÓMO SE GENERAN (importante)
----------------------------
Las páginas NO se editan a mano: se generan desde un shell compartido.
  _build/gen.py    -> head + header + footer + cierre (comunes a las 6)
  _build/pages.py  -> el contenido de cada página
Para cambiar algo:
  1. editar _build/pages.py (contenido) o _build/gen.py (estructura común)
  2. cd _build && python gen.py
  3. desplegar
Así header, pie, metadatos y contacto no pueden desincronizarse entre páginas.
El generador NO se publica (ver .vercelignore).

Estilos y comportamiento compartidos: assets/site.css + assets/site.js
El bloque CONFIG al inicio de site.js tiene todo el contacto.

DISEÑO v2
---------
Negro #0A0A08 + el amarillo real de marca #FBE134.
Tipografías: Newsreader (display, CON EJE ÓPTICO) + Instrument Sans (texto).

Decisiones que vienen de leer el CSS de producción de ~60 sitios:
- Ratio display:cuerpo = 7.3:1 (124px / 17px). Los servicios premium reales
  viven en 4.5-7.5:1, NO en 20:1 como los estudios de diseño.
- Newsreader trae eje `opsz`: las formas ya se ajustan solas al crecer, así que
  apretar más el tracking sería doble corrección. Por eso -0.032em y no -0.06em.
- El amarillo se usa como SUPERFICIE (resaltador del titular + bloque a página
  completa), nunca como texto pequeño: sobre negro da 15:1 como fondo.
- Rampa de 6 superficies por luminosidad (#0A0A08 -> #302E20). En oscuro se eleva
  con luz, no con sombra.
- Texto en 4 niveles; el primario NUNCA es blanco puro (#F5F3E8).
- ink-4 = #8A8674 -> 5.42:1. Con #6E6A58 daba 3.65:1 y fallaba AA.
- Escala de espaciado de 8 pasos (8 -> 220px, rango 27:1). De ahí sale la
  densidad variable: la sección de pasos aprieta, el bloque amarillo respira.
- Una sola curva de animación: cubic-bezier(.16,1,.3,1) = easeOutExpo.
- Radios de 2px (el 38% de los sitios medidos usa <= 4px).
- Grano fractalNoise como data-URI, opacidad .13.

🚨 REGLA DE ACCESIBILIDAD QUE NO SE PUEDE ROMPER
El tamaño máximo de una fuente fluida no puede pasar de 2.5x el mínimo, o falla
